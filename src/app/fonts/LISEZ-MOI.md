# Police Graphik

Le site utilise **Graphik** (Commercial Type) pour tous les textes : fichiers `Graphik-Light`, `Regular`, `RegularItalic`, `Medium`, `Semibold` dans ce dossier, chargés dans `src/app/layout.tsx`.

**Licence** : ces fichiers ont été fournis par Antoine. Avant toute mise en ligne publique, il faut une **licence web** achetée sur commercialtype.com au nom du studio. Un site public rend les fichiers de police téléchargeables : sans licence web, c'est une infraction au droit d'auteur.

Pour passer aux fichiers web officiels (.woff2) une fois la licence achetée : les déposer ici et remplacer les chemins `.otf` par les `.woff2` dans `layout.tsx`.
